# Melstar Manufacturing Systems — Website

Static, build-free website for Melstar Manufacturing Systems Pvt Ltd (KIADB Industrial Area, Obadenahalli, Doddaballapura).

- `index.html` — page structure
- `styles.css` — light aurora / glass theme and animations
- `main.js` — scroll reveals, magnetic buttons, 3D tilt, live IST clock & plant status, simulated telemetry
- `hero3d.js` — Three.js meshing-gear hero scene

Run locally: `python -m http.server 5510` and open http://localhost:5510. Deployable as-is to GitHub Pages.
